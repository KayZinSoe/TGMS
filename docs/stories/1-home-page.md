# Story: Home Page

As a user, I want to see a simple dashboard that welcomes me and shows core actions, so I can quickly understand the app and navigate to features.

Acceptance criteria:
- Shows app title and short description
- Displays a friendly greeting component
- Header contains a placeholder for navigation

Notes:
This story maps to `frontend/src/pages/Home.jsx` and `frontend/src/layouts/MainLayout.jsx`.
